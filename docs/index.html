Open-source media tool

mergeme

Turn a Google Photos export — or any folder of GoPro, DJI, phone, or other camera clips — into one chronological, YouTube-ready video, with dates, month cards, photos, clips, and a quiet soundtrack.

Cross-platform

Prebuilt binaries are available for Linux, Intel and Apple Silicon macOS, and Windows.

Simple runtime

Install ffmpeg, ffprobe, and exiftool, then point mergeme at any export or camera folder.

Any source

Google Photos Takeout, GoPro, DJI, dashcams, phone dumps — anything with videos and pictures.

Install in one step

Install the latest release, then make sure the media tools are available on your computer.

macOS or Linux

curl -fsSL https://raw.githubusercontent.com/fabiostawinski/mergeme/main/scripts/install-mergeme.sh | sh

Install the runtime tools with brew install ffmpeg exiftool on macOS, or sudo apt-get install ffmpeg libimage-exiftool-perl on Debian or Ubuntu.

Windows PowerShell

irm https://raw.githubusercontent.com/fabiostawinski/mergeme/main/scripts/install-mergeme.ps1 | iex

Install the runtime tools with winget install Gyan.FFmpeg OliverBetz.ExifTool.

Check your setup with mergeme --help. The installer places the command in ~/.local/bin on macOS/Linux and ~/bin on Windows.

How a video gets made

One pass over your folder, from raw clips to a finished, publish-ready file.

  1. 1

    Point at a folder

    Google Photos Takeout, a GoPro or DJI card dump, phone exports — anything with videos and pictures, scanned recursively.

  2. 2

    Resolve capture time

    Takeout sidecar JSON first, then EXIF CreateDate/DateTimeOriginal via exiftool, then file mtime as a last resort.

  3. 3

    Sort & batch

    Everything is ordered chronologically and split into ~1GB batches, encoded in parallel.

  4. 4

    Normalize

    Every clip is re-encoded to a common 1920x1080/30fps/AAC-stereo format so mixed cameras concatenate cleanly.

  5. 5

    Insert cards

    A "Month Year" title card marks each new month, your title is burned onto the first second, and any custom markers land where you asked.

  6. 6

    Mix the soundtrack

    Your song is looped or trimmed to fit, mixed in quietly under the original audio, and fades out under a closing black screen.

  7. 7

    Concatenate

    Batches are joined into one finished, chronological, YouTube-ready MP4.
